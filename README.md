# VIDEO·FIELD

Видео (до 20 с, источник до 2K) → облако точек с эффектами → MP4 до 2560×1440 (или 1440×2560).
Всё считается в браузере: видео идёт в WebGL как текстура, эффекты считаются на GPU,
экспорт покадровый (seek → рендер → WebCodecs H.264 → mp4-muxer).

Запуск локально: `python3 -m http.server` и открыть http://localhost:8000
Нужен Chrome / Edge / Safari 16.4+ (WebCodecs).

Эффекты: пульсация, волны, магнит, турбулентность, скан-линия, парение, ветер, разлёт/сборка,
облёт и ракурс камеры, трек-точки со связями и подписями.
Звук оригинала пока не переносится.

Слои графики (поверх облака или вместо него): узлы и фигуры по контурам (Sobel), связи
(Delaunay, соседи, цепочка, радиальные), дизеринг-печать (Atkinson, Floyd–Steinberg, Bayer, шум),
спектральная завеса, плоттер-линии в духе Pintr. Все режимы наложения, цветовые схемы графики.

`index.html` + `app.js` — основной проект, `video-field.html` — тот же сайт одним файлом
(после `python3 build.py`-подобной сборки; на Pages лежит как `single.html`).

Сторонние библиотеки (vendor/): three.js r160 (MIT), mp4-muxer 5.1.3 (MIT).
